What is ReqStorm

API testing infrastructure, from one MCP server

ReqStorm implements the Model Context Protocol and runs over stdio, so it plugs straight into Claude Desktop, VS Code, Cursor, and other MCP hosts. Describe what you want in plain language — ReqStorm drives real, autocannon-powered traffic and returns structured results.

What ships in the box

  • Real latency percentiles from a live hdr-histogram — p50/p95/p99/p999
  • Warm-up vs steady-state phases; thresholds evaluated on steady state only
  • JSONPath extraction with 13 matcher operators
  • Multi-step {{var}} chaining with request-to-request interpolation
  • OpenAPI 3.x contract validation with breaking-change detection
  • Progress notifications on long-running jobs
Quick start

Up and running in minutes

Add one entry to your MCP host config. No app to install on the client. 

{
  "mcpServers": {
    "reqstorm": {
      "command": "npx",
      "args": ["-y", "reqstorm"]
    }
  }
}
You:

Run a ReqStorm benchmark against https://api.example.com/health with 10 connections for 10 seconds.

The toolbox

14 tools. Three disciplines.

Every tool is a first-class MCP tool with a Zod-defined input schema and structured output. Exact descriptions below mirror the project documentation.

⚡ Performance 7 tools

benchmark

Measure throughput and p50/p95/p99/p999 latency. Results include overall, warm-up, and steady-state data.

smoke

Quickly check that an endpoint responds with the expected status and body.

load-test

Run sustained traffic and evaluate steady-state maxP95, maxP99, and maxErrorRate thresholds.

spike

Run baseline, sudden surge, and recovery phases; measure recovery against baseline latency.

soak

Run long-lived traffic in periodic chunks to find memory leaks, exhaustion, and performance drift. Default duration is 30 minutes.

stress-test

Ramp concurrency step by step until latency or error-rate thresholds identify a breaking point.

compare

Compare two endpoints or configurations side by side, optionally repeating each target up to five times.

🔧 Functional & contract 5 tools

validate

Send one request and assert on JSONPath values, types, comparisons, regexes, array properties, and response-time thresholds.

chain

Execute up to 20 ordered requests, extract values from responses, interpolate them into later requests, and assert each step.

contract-check

Check a running API against an OpenAPI 3.x JSON/YAML document, including status codes, schemas, content types, and required fields.

fuzz

Mutate request bodies with boundary, type-swap, injection, overflow, missing-field, Unicode, format, and null-field strategies.

regression

Compare steady-state performance with a saved .reqstorm/ baseline and optionally save the current run as the new baseline.

🛡️ Security & profiling 2 tools

security-scan

Run selected checks for authentication bypass, IDOR, security headers, data exposure, rate limiting, method override, content-type mismatch, and path traversal.

profile

Inspect latency distribution, status-code counts, throughput stability, and error/timeout breakdowns.

Capabilities

Built for real API work

Under the hood it wraps the autocannon load engine, hdr-histogram latency recording, and swagger-parser — so numbers come from real measurement, not guesswork.

🎯

Pass/fail thresholds

Load tests and regressions evaluate p95, p99, and error-rate limits against steady-state metrics and return a clear verdict.

🚀

Warm-up aware

Benchmark runs split into warm-up and steady-state phases. Warm-up results are reported, not discarded — thresholds only judge steady state.

🔗

Workflow chaining

chain runs up to 20 ordered requests, pulling values out of responses with JSONPath and interpolating them via {{var}}.

🧮

13 matcher operators

equals, notEquals, contains, matches, gt/lt/gte/lte, exists, notExists, isType, isArray, hasLength.

📜

OpenAPI contract checks

contract-check validates live endpoints against OpenAPI 3.x — status codes, response schemas, content types — and surfaces breaking changes.

🎲

Fuzzing strategies

Boundary, type-swap, injection, overflow, missing-field, Unicode, format, and null-field mutations with quick/normal/thorough depth.

🛡️

Security scanning

Auth-bypass, IDOR, security headers, data exposure, rate limiting, method override, content-type mismatch, and path-traversal checks.

📈

Regression baselines

Save runs with saveAs into .reqstorm/ and diff later runs against them in CI or local workspaces.

🩺

Soak analytics

soak samples real process.memoryUsage() heap/RSS per snapshot and derives a memory trend from actual growth.

⏱️

Progress reporting

Long-running tools emit MCP progress notifications as work proceeds, so clients can render live status.

Installation

Two ways to run it

01

Via npx (no install)

The first run downloads the package from npm. This is what the MCP host config uses. 

$ npx -y reqstorm
02

Global install

Available as a global binary for any client, or for scripting and CI glue.

$ npm install --global reqstorm
03

Requirements

Runs over stdio, bundled from dist/. Requires Node.js 18+. 

$ node -v
v20.12.0  # 18 or newer ✓
